完整 ROS XML lint 会尝试访问 ROS 远程 XSD；网络返回空内容时该项会失败，
本地 `xmllint` 对包 XML 已通过。这是检查环境问题，不是包 XML 解析错误。

## 当前结论

升级版已经实现动态球权仲裁、同周期冲突的低编号决胜、后卫接管、移动防守锚点、
接近阶段机器人避让和风险型边线/解围通道。当前仍不能宣称已经达到正式比赛级别：
蓝方短局效率、强对手下的球权稳定性和长局防守保持还需要更多独立种子回归。
`unirobot` 只用于回归，不是比赛官方指定对手；正式成绩取决于与其他队伍实际比赛。

#### 当前判断

地图可靠性、滤波位姿在边界决策中的使用、裁判罚站测试链和多种压力场景已向前推进，
但新测试局均未进球。当前最明确的成绩问题仍是有效射门转化和样本间波动；下一轮应
增加多随机种子、红蓝配对与多类真实/经校准对手统计，再决定是否改战术参数。现有视觉
只输出单个通用机器人候选框，距离/身份可靠性不足，故本轮没有虚构多对手轨迹地图，
也没有让低置信候选参与决策。

#### 当前结论与下一测量门槛

定位和世界球估计已有可量化基线：自机平滑将典型误差约减半，球地图精度强烈依赖角色/视角，
双机简单平均仅显示很小的收益。二维台必须包含实测噪声和不确定性，不能给策略完美真值。
下一步做按视角/距离分层的误差分析及受控直行、转向、左右脚踢球实验；得到速度、转向、球衰减
和踢球方向/距离分布后，再将这些区间作为二维模拟参数，并用多种对手评估共享规划。
