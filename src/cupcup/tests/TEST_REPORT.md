  当前项目运动基础设施的最小兼容修复，不依赖初赛工作区。

## 已知环境限制

完整 ROS XML lint 会尝试访问 ROS 远程 XSD；网络返回空内容时该项会失败，
本地 `xmllint` 对包 XML 已通过。这是检查环境问题，不是包 XML 解析错误。

## 当前结论

升级版已经实现动态球权仲裁、同周期冲突的低编号决胜、后卫接管、移动防守锚点、
接近阶段机器人避让和风险型边线/解围通道。当前仍不能宣称已经达到正式比赛级别：
蓝方短局效率、强对手下的球权稳定性和长局防守保持还需要更多独立种子回归。
`unirobot` 只用于回归，不是比赛官方指定对手；正式成绩取决于与其他队伍实际比赛。
